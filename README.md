# TideGaze

TideGaze is a high-performance, real-time data processing engine, enabling scalable data aggregation and caching for distributed systems.

TideGaze is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/TideGaze.git`
2. `cd TideGaze`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
